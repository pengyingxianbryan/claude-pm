# AUDIT.md Template

Template for `.pm/audits/AUDIT-{YYYY-MM-DD}-{scope}.md` — written by `/pm:audit`.

**Purpose:** One dated, diffable record per audit run so the next run can say what got better and what is still open. Findings promoted to `.pm/ISSUES.md` carry the audit id as origin.

---

## File Template

```markdown
# Audit — {scope} — {YYYY-MM-DD}

| Field | Value |
|-------|-------|
| Scope | security / seo / observability / ci / all |
| Commit | [short SHA] |
| Previous | [AUDIT-...md or —] |
| Result | PASS / FAIL (any Critical or High open) |

## Score

| Area | Critical | High | Medium | Low | Δ vs previous |
|------|----------|------|--------|-----|---------------|
| Security | 0 | 1 | 3 | 2 | −2 |
| … | | | | | |

## Findings

### AUD-001: [title]

| Field | Value |
|-------|-------|
| Severity | Critical / High / Medium / Low |
| Area | security / seo / observability / ci |
| Check | [skill § reference, e.g. security-gate §3] |
| Location | `path/to/file.ts:42` |
| Status | Open / Fixed in [PR] / Accepted (reason) |

**Finding:** [what is wrong, one paragraph]
**Evidence:** [command + output excerpt]
**Fix:** [concrete change]
**Promoted to:** ISSUE-NNN / — 

---

## Passed Checks

- [area §n] [check] ✓
- …

## Not Applicable

- [area §n] [check] — [why: no public pages / no crons / …]

---
*Generated by /pm:audit | {timestamp}*
```

## Severity Rubric

| Severity | Meaning | Action |
|----------|---------|--------|
| Critical | Exploitable now, or secret exposed | Fix before anything else; rotate |
| High | Exploitable with effort, or production blind to failure | Fix in current phase |
| Medium | Defence-in-depth gap, SEO page missing index basics | Log to ISSUES.md, next phase |
| Low | Hygiene | Log, batch |
